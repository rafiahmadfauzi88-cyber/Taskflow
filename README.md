# TaskFlow - Sistem Pengelolaan Tugas & Deadline Mahasiswa

Aplikasi web sederhana berbasis Python dan Streamlit untuk membantu mahasiswa mencatat daftar tugas individu maupun kelompok dari berbagai mata kuliah, memantau sisa tenggat waktu (*deadline*), mengelompokkan tingkat urgensi secara otomatis, serta melihat statistik progres penyelesaian tugas.
